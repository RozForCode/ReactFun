2. Creating a component that focuses an input field as soon as it is rendered:
 import React, {useEffect, useRef} from 'react';
 function focusInput(){
    const inputRef = useRef(null);
    useEffect(()=>{
        inputRef.current.focus();
    },[]);
    return (
        <div>
            input ref={inputRef} type='text' />
        </div>
    )
 }

creating simple counter component using useReducer 
--A counter component in React is a simple UI element that tracks and displays a numeric value, usually allowing users to increment or decrement that value through some form of interaction, like clicking a button.--
import React, {useReducer} from 'react';

function counterReducer(state,action){

        switch(action.type){
            case 'increment':
            return state+1;
            case 'decrement:
            return state-1;
            default:
            return state;
        }
}
function counter(){
    const [cont,dispatch] = useReducer(counterReducer, 0)
    return (
        <div>
        <p>Count: {count}</p>
        <button onClick={()=> dispatch({type:'increment'})}>Increment</button>
        <button onClick={()=> dispatch({type:'decrement'})}>Descrement</button>
        </div>
    )
}

useReducer - hook that manages state logic - takes a reducer function and an initial state
counterReducer - checks the action.type and modifies state
dispatch - sends action to the reducer to update the state.

dispatch argument here is shorthand of
const action = {type:'increment'}
dispatch(action);
short hand is
dispatch({type:'increment'})
